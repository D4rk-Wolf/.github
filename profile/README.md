# D4rk-Wolf

D4rk-Wolf is the independent software studio of Connor “Turkish” Simmons, based in Manchester, UK.
Founded in April 2023, the studio ships production-grade Android apps, developer tools, and hardware-aware software with a strong focus on data ownership, practical engineering, and clarity over hype.

## What We Build

- **DoseFlow** — medication tracking for Android
- **AutoVibe** — atmosphere automation for Android
- **GarageGuardian** — IoT garage monitoring with Android + ESP32
- **JounoApp** — markdown journaling for Android
- **AI Document Templates** — browser and desktop developer tool for AI documentation
- **Smart Helmet** — cyclist safety hardware prototype
- **Nexus** — web3 social platform in active development
- **Sovereign OS** — custom Linux platform, internal work in progress

## Studio Philosophy

- Small teams ship faster than committees.
- Open source when it makes sense, and on-device data where it doesn’t.
- No commissions, no roadmap promises without code already written.
- Production-ready work first, polish and sustainability second.

## Technology

- Kotlin · Jetpack Compose
- React · Tauri
- ESP32 · Linux
- Browser, desktop, Android, embedded systems

## Current Focus

The studio keeps its work lean and real:
- shipping apps already in the Play Store
- maintaining open-source developer tooling
- building hardware-aware products with no unnecessary telemetry
